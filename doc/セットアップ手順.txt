セットアップ手順
プロジェクトを動かすための手順をまとめます：
1. プロジェクトの作成
IntelliJ IDEAで新規Mavenプロジェクトを作成します：

File → New → Project
Mavenを選択
Name: InsuranceApp
GroupId: jp.insurance
ArtifactId: InsuranceApp
JDK: 17以上を選択
Createをクリック

2. ファイルの配置
上記で提供したコードを、プロジェクト構造に従って配置してください：
InsuranceApp/
├── pom.xml (ルートに配置)
├── src/
│   └── main/
│       ├── java/jp/insurance/system/ (Javaコード)
│       ├── resources/init.sql (リソースフォルダ直下)
│       └── webapp/
│           ├── WEB-INF/
│           │   ├── web.xml
│           │   └── views/ (JSPファイル)
│           ├── css/style.css
│           └── index.jsp
3. MySQLデータベースの準備
MySQLがインストールされていることを確認してください。データベースは自動的に作成されます。
4. Mavenの依存関係をダウンロード
IntelliJ IDEAで：

右側のMavenタブを開く
Reload All Maven Projects（更新アイコン）をクリック

5. Tomcatの設定

Run → Edit Configurations
+ → Tomcat Server → Local
Application ServerでTomcat 10.1を設定
Deploymentタブで**+**をクリック
Artifact → InsuranceApp:war explodedを選択
Application contextを/に設定
OKをクリック

6. アプリケーションの起動

Runボタン（緑の三角）をクリック
ブラウザで http://localhost:8080/ にアクセス

7. 動作確認

契約一覧: http://localhost:8080/policies

早期更改率の表示を確認
タブで絞り込みを確認
要注意バッジを確認


事故一覧: http://localhost:8080/accidents

滞留バッジを確認
対応中/完了タブを確認



主な機能
契約管理

✅ 契約一覧（タブ切り替え）
✅ 契約検索（契約番号・契約者名）
✅ 契約新規登録
✅ 契約詳細表示
✅ 契約更新（期間チェック付き）
✅ 更新取消（当日限定）
✅ 契約解約
✅ 解約取消（当日限定）
✅ 要注意期間バッジ
✅ 早期更改率（当年度・当月）

事故管理

✅ 事故一覧（対応中・完了タブ）
✅ 事故新規登録
✅ 事故詳細表示
✅ ステータス遷移（OPEN→IN_PROGRESS→RESOLVED）
✅ 対応した（last_contacted_at更新）
✅ メモ保存
✅ 滞留バッジ（7日以上）

トラブルシューティング
データベース接続エラー

MySQLが起動しているか確認
Db.javaの接続情報が正しいか確認（ポート、パスワード）

JSPが表示されない

Tomcatが正しく設定されているか確認
web.xmlがWEB-INFフォルダにあるか確認

Bootstrapが適用されない

インターネット接続を確認（CDNから読み込んでいます）
